La idea principal del proceto es crear un e-commerce de una pagina dedicada
a la venta de videojugos.,

----------------------------
-Funcionalidades principales

Catálogo de juegos
Se podrá ver un catálogo de juegos disponibles para comprar.
Cada juego contará con etiquetas para poder organizarlos y filtrarlos por género.
Se incorporará una barra de búsqueda para encontrar juegos.
Se podría analizar si existe alguna librería o API que permita importar los juegos más relevantes de plataformas como Steam para no tener que agregarlos 1 x 1 a mano.

Sistema de compras
La aplicación contará con un sistema de compra de juegos.
También tendrá una sección de carrito, donde el usuario podrá agregar los juegos que quiera comprar antes de realizar la compra.

Biblioteca
Cada usuario tendrá una biblioteca donde aparecerán todos los juegos que haya comprado.
La idea es que esta biblioteca funcione de una manera similar a la biblioteca de Steam.

Comentarios y reseñas
Cada juego contará con una sección de comentarios, donde los usuarios de mi plataforma podrán dejar sus opiniones y reseñas.

Organización y filtrado
Para facilitar la búsqueda de juegos, se utilizarán etiquetas en cada juego.

Estas etiquetas permitirán:
Organizar los juegos.
Filtrar por género.
Facilitar las búsquedas.
Encontrar juegos con características similares.


---------------------------
POSIBLES IDEAS A FUTURO
---------------------------
Sistema de guardado en la nube

La aplicación tendrá la opción de guardar los save games (muy generalmente de pocos KB) en la nube.
Inicialmente, se permitirá guardar los saves de hasta 3 juegos distintos de forma gratuita.

Si el usuario quiere guardar los saves de más de 3 juegos, se buscará evaluar la posibilidad de ofrecer una cuenta Premium de por vida, aunque esto todavía está por definirse.

Perfil de usuario
Cada usuario tendrá una sección de perfil, con un funcionamiento y diseño similar al perfil de Steam.
En este perfil se podrían mostrar, entre otras cosas, los juegos que posee y la información relacionada con su actividad dentro de la plataforma.
